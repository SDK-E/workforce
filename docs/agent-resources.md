# Agent Resources Manager

The ARM is a durable control-plane identity, not a model session. It converts validated job requirements into an explainable probationary agent blueprint.

Role, skills, instructions, permissions, engine policy, sandbox, and probation criteria derive from the actual job. The ARM refuses contradictory requirements instead of creating an over-privileged generic agent.

Performance separates employee behavior from model, infrastructure, permission, tool, and requirement failures. One attempt cannot justify termination. Suspension is reversible; termination preserves all records and outputs.
