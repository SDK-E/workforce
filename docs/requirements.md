# Product requirements

The workforce is generic, multi-organization, local-first, and Docker-first. A durable CEO is always available in the control plane. An Agent Resources Manager adapts role, instructions, skills, tools, model policy, resources, and sandbox permissions to each job.

Hiring requires a verified capability or capacity gap, manager, responsibilities, probation criteria, permission policy, and audit reason. Suspension is reversible. Termination preserves identity, work, chats, attempts, and performance evidence.

Agents collaborate through durable channels and task threads. Mail is a formal handoff mechanism, not the only collaboration surface. Messages have delivery state and are checked at safe checkpoints.

The TUI defaults to human-readable phases, meaningful activities, files, decisions, evidence, blockers, and acceptance progress. Raw events remain searchable behind an advanced view.

The supervisor enforces one attempt per employee, one container per attempt, bounded concurrency, durable leases, stale detection, model failover, circuit breakers, child cleanup, crash recovery, and no false completion.
